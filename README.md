# TubeChat AI - YouTube Video Chatbot

An AI-powered application that allows you to summarize YouTube videos and chat with them using RAG (Retrieval-Augmented Generation).

## Technologies Used
- **Backend**: FastAPI (Python 3.14)
- **AI**: OpenAI GPT-4o & text-embedding-3-small
- **Vector DB**: Pinecone
- **Database**: Supabase (PostgreSQL)
- **Frontend**: Vanilla JS, HTML, CSS (Glassmorphism UI)

## Features
- ✨ **Instant Summaries**: Get the key takeaways from any YouTube video in seconds.
- 💬 **Interactive Chat**: Ask specific questions about video content using advanced vector search.
- ☁️ **Cloud Native**: Powered by Supabase and Pinecone for permanent storage.
- 🎨 **Premium UI**: Clean, dark-mode design with smooth animations.
